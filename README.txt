OSI — SITE WEB VITRINE
======================

Contenu
- index.html : structure et textes du site
- styles.css : design responsive ordinateur/mobile
- script.js : menu mobile et année automatique
- assets/favicon.svg : icône du site

Tester sur votre ordinateur
1. Décompressez le dossier.
2. Ouvrez index.html dans Chrome ou Edge.
3. Pour modifier les textes, ouvrez index.html dans VS Code.
4. Pour modifier les couleurs et la mise en page, ouvrez styles.css.

Mise en ligne
- Téléversez index.html, styles.css, script.js et le dossier assets à la racine publique de votre hébergeur (souvent htdocs ou public_html).
- Vérifiez que index.html se trouve directement dans ce dossier public.
- Le site est statique : il peut présenter les services et ouvrir WhatsApp/e-mail, mais ne comporte pas encore de base de données, de panier de paiement, de compte client ni de tableau de bord de commande.
